Proyecto: Base de datos de una tienda musical
Este proyecto consiste en el diseño y desarrollo de una base de datos relacional en PostgreSQL destinada a la gestión de una tienda de música. Su finalidad es almacenar, organizar y consultar información sobre artistas, álbumes musicales y ventas realizadas.

La base de datos cuenta con un catálogo de 31 artistas y sus respectivos álbumes, disponibles en diferentes formatos físicos: CD, vinilo y casete. Cada álbum dispone de información sobre su fecha de lanzamiento, listado de canciones, precio y unidades disponibles en stock.

Además, permite registrar las ventas realizadas, consultar el inventario y obtener estadísticas comerciales mediante consultas SQL.
Características principales
- Gestión de artistas y sus nacionalidades.
- Catálogo de 31 álbumes musicales reales.
- Almacenamiento de canciones mediante arrays de PostgreSQL.
- Gestión de precios, formatos y stock.
- Registro de 50 ventas de ejemplo.
- Relaciones entre tablas mediante claves primarias y foráneas.
- Validación de datos mediante restricciones CHECK y NOT NULL.
- Creación y reconstrucción del esquema mediante un script SQL.
Tecnologías utilizadas
- PostgreSQL: sistema gestor de bases de datos.
- pgAdmin 4: herramienta de administración de bases de datos.
- SQL: lenguaje utilizado para la definición, manipulación y consulta de datos.
Objetivo del proyecto
Aplicar los conocimientos adquiridos sobre bases de datos relacionales, integridad referencial, restricciones, arrays y consultas SQL, simulando un entorno comercial real dedicado a la venta de música en formato físico.
